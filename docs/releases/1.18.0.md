# Halo Battery 1.18.0

## What's new

- A native Windows 11 Settings window with per-device configuration, a live tray
  preview, adjustable rings, filled icons and percentage display.
- Custom tray icons from Iconify, with offline use of applied icons. The catalog
  runs in a separate process and releases its browsing memory when Settings closes.
- Lower startup and browsing memory use through lazy loading, compressed artwork
  and smaller temporary buffers. Bluetooth battery reads run inside the app.
- A refreshed tray menu with bold device names, compact battery details, inline
  renaming and per-device hiding, alert thresholds and settings.
- More supported devices and connection modes, including ASUS TUF Gaming H3
  Wireless, Akko Verge S9 Ultra, the VXE R1 Pro Max cable variant, and additional
  Pulsar receiver models. Existing device identities and settings are preserved
  across supported cable/receiver transitions.
- More reliable controller identity, battery validation, custom-icon search and
  multilingual text handling, plus many Settings and tray interaction fixes.
- Pre-release users can update to stable 1.18.0 even when the numeric version is
  unchanged.
- Updated project documentation with theme-aware previews and a Russian README.
