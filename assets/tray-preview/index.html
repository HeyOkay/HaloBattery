Windows 11 System Tray

Windows tray styling with HaloBattery device icons. Choose a theme, DPI, and independent battery states.

Device state

Each device keeps its own state. Click a device icon to select it here.

Click the tray arrow for hidden icons or the language indicator to switch input language. Press Esc or click outside to dismiss.

System symbols use Segoe Fluent Icons; text uses Segoe UI Variable. Device artwork and rings are from HaloBattery.
Device values are a local preview. Integration notes
